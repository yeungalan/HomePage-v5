# JLPT N4 Grammar Notes

## 可能形
| グループ | 変形 |
| --- | --- |
| I | い→え |
| II | +られ |
| III | きます→こられます |
| III | します→できます |
を→が (with the potential form, the object particle を becomes が)

## 意向形
| グループ | 変形 |
| --- | --- |
| I | い→お |
| II | +よう |
| III | きます→こよう |
| III | します→しよう |

## 禁止形
| グループ | 変形 |
| --- | --- |
| I | い→え |
| II | +ろ |
| III | きます→こい |
| III | します→しろ |


## 條件形
| グループ | 変形 |
| --- | --- |
| I | い→え+ば |
| II | +れば |
| III | きます→くれば |
| III | します→すれば |

## 受身形
| グループ | 変形 |
| --- | --- |
| I | い→あ＋れ |
| II | +られ |
| III | きます→され |
| III | します→こられ |
