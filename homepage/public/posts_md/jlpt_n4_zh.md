# JLPT N4 文法筆記

## 可能形
| グループ | 変形 |
| --- | --- |
| I | い→え |
| II | +られ |
| III | きます→こられます |
| III | します→できます |
を→が（使用可能形時，受詞助詞を改為が）

## 意向形
| グループ | 変形 |
| --- | --- |
| I | い→お |
| II | +よう |
| III | きます→こよう |
| III | します→しよう |


```math
\left[
\begin{array}{l}
  \text{V}_{\text{普通形}} \\
  \text{形容詞}_{\text{い}} \\
  \text{形容詞}_{\text{な}}\text{（}\cancel{\text{だ}}\rightarrow \text{な）} \\
  \text{N（}\cancel{\text{だ}}\rightarrow \text{な）}
\end{array}
\right]\text{んです}
```

```math
\left[
\begin{array}{l}
  \text{V}_{\text{て形}}
\end{array}
\right]\text{いただけませんか}
```

```math
\text{疑問詞＋V}_{\text{た形}}\text{らいいですか}
```

```math
\text{Nは}\left[
\begin{array}{l}
  \text{好きです・嫌いです} \\
  \text{上手です・下手です} \\
  \text{あります・います・etc}
\end{array}
\right]
```

が[みえます・聞こえます]
不受個人意志控制，自然而然看得見／聽得見

ができます
完成／建成

しか
只能做某事；一定配合否定形使用，帶有「不足、不夠」的語感

Nは…。Nは…。
用は對比兩件事物

```math
\left[
\begin{array}{l}
  \text{V}_{\text{ます形}}
\end{array}
\right]\text{ながら}\left[
\begin{array}{l}
  \text{V}_{\text{ます形}}
\end{array}
\right]
```

```math
\left[
\begin{array}{l}
  \text{V}_{\text{て形}}
\end{array}
\right]\text{います}
```
1. 表示正在進行的動作
2. 表示習慣性的行為
3. 表示動作完成後留下的狀態（自動詞）…が…


```math
\left[
\begin{array}{l}
  \text{文}_{\text{普通形}}
\end{array}
\right]\text{し、}\left[
\begin{array}{l}
  \text{文}_{\text{普通形}}
\end{array}
\right]\text{し、～}
```

それで
所以

```math
\left[
\begin{array}{l}
  \text{V}_{\text{て形}}
\end{array}
\right]\text{しまいました・しまいます}
```
已經完成／將來會完成（亦可帶有遺憾的語感）


ありました
表示現在才發現某物，並不表示它過去在這裡

```math
\left[

  \text{V}_{\text{て形}}
\end{array}
\right]\text{あります}
```
他動詞
表示某人的動作所造成的狀態

```math
\left[

  \text{V}_{\text{て形}}
\end{array}
\right]\text{おきます}
```
