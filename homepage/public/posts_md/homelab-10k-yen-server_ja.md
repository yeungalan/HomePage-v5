# 1 万円の自宅サーバー：Raspberry Pi ではありません

私の自宅サーバーに SSH でログインすると、プロンプトには `pi@debian-server-jp` と表示されます。みんな Raspberry Pi だと思いますが、違います。このユーザー名は Raspberry Pi を使っていた頃の古い癖で、変えるのが面倒なだけです。

本当のマシンは、約 **1 万円**で買った中古の **NEC Mate** 業務用ミニ PC です。日本にはこういう PC がたくさんあります。企業が数年間リースした業務用 PC が、中古市場で安く売られるのです。Raspberry Pi 5 のキットと同じくらいの値段で、本物の SATA ドライブ、12 GB の RAM、Intel グラフィックスを備えたクアッドコアの x86 マシンが手に入りました。

## ハードウェア

中身はこうなっています：

| 部品 | 詳細 |
|---|---|
| 型番 | NEC Mate タイプ ML（PC-MKL31CZG6）、ミニ PC 筐体 |
| CPU | Intel Core i3-9100T、4 コア / 4 スレッド、3.1–3.7 GHz、TDP 35 W |
| グラフィックス | Intel UHD Graphics 630 |
| チップセット | Intel B360 |
| RAM | 12 GB DDR4 SO-DIMM（8 GB SK Hynix + 4 GB Samsung） |
| ストレージ | 500 GB WD Black 2.5 インチ ノート用 HDD、7200 rpm |
| ネットワーク | Intel I219-V ギガビット Ethernet、Intel Wireless 8265 Wi-Fi |
| ファームウェア | 2019 年 6 月の NEC BIOS、UEFI |
| OS | Debian 13（trixie）、カーネル 6.12 |

このスペック表について正直なメモをいくつか：

- **RAM が揃っていません。** 一枚は 2133 MT/s の 8 GB、もう一枚は 2666 MT/s の 4 GB なので、2133 で動いています。問題なく動きますし、タダでもらったものなので文句はありません。
- **システムディスクは回転式のノート用ドライブです。** 7200 rpm の WD Black で、2.5 インチ HDD としてはほぼ最上級ですが、それでも HDD です。詳しくは後述します。
- **i3-9100T の「T」は重要です。** 低消費電力版のチップで、電源を切らないマシンにはまさに理想的です。

## なぜ Raspberry Pi ではないのか？

Raspberry Pi は好きですが、一日中たくさんのコンテナを動かすマシンなら、中古の業務用 PC がほぼすべての点で勝ちます：

- **x86 互換性。** どの Docker イメージもそのまま動きます。ARM ビルドを探す必要はありません。
- **本物のストレージ。** いずれ消耗する SD カードではなく、SATA ポートがあります。
- **使える GPU。** UHD 630 は動画のデコードをこなし、カメラの AI 物体検出も動かします（後述）。
- **価格。** 電源込みで本体全部が約 1 万円。

代わりに消費電力とサイズで劣りますが、それも思ったより優秀です。ほぼアイドル状態のとき、プロセッサ自体の消費電力は約 **1 W** しかありません。コンセントで測った本体全体の値ではありませんが、チップが一日の大半を眠って過ごしていることがわかります。

## 動かしているもの

現在動かしているのはこちらです：

- **ArozOS**：ウェブデスクトップ兼ファイルマネージャー。ArozOS の開発用マシンとしても使っています。
- **Frigate NVR**：防犯カメラ用。物体検出は **OpenVINO** を通して内蔵 GPU で動くので、Coral TPU は不要です。
- **Munin**：監視用。CPU、メモリ、温度、帯域、ディスク I/O、時刻のずれをすべてグラフ化しています。
- **OnlyOffice Document Server**：ブラウザでドキュメントを編集するため。
- **Virtual DSM**：コンテナで動く Synology DSM。Synology の API のテストやリバースエンジニアリングに使っています。
- **Samba**：ネットワークファイル共有。WS-Discovery で Windows からも見つけられます。
- **京王線のリアルタイムボード**：京王線の列車位置データを机用の横長ダッシュボードにする、Go で書いた小さなサービス。

アクセスには、ルーターのポートを開けずにウェブサービスを公開できる **Cloudflare Tunnel** と、外出先からプライベートに接続できる **Tailscale** を使っています。

## 簡単なヘルスチェック

中古で、しかも中古のドライブ付きで買ったので、状態には気を配っています：

- **温度：** CPU は約 **40°C**、ドライブは約 **36°C**。小さな NEC の筐体でも 35 W のチップを問題なく冷やせています。
- **ドライブの健康状態：** ヘルスチェックは合格で、今のところ不良セクタはありません。使用時間は約 **13,900 時間**で、ほとんどは前のオフィスでの使用によるものでしょう。
- **注意点：** ドライブのヘッド退避回数がすでに約 **139,000 回**に達しています。ノート用ドライブは省電力のために頻繁にヘッドを退避させるので、眠らないサーバーでは回数がどんどん増えます。緊急事態ではありませんが、次のアップグレードの十分な理由です。
- **メモリ：** 上記すべてが約 4 GB に収まるので、12 GB にはまだ十分な余裕があります。

## 次にアップグレードしたいもの

1. **OS を SSD に移す。** すべてが速くなり、ヘッド退避の心配もなくなります。HDD はカメラ録画用の大容量ストレージとして残せます。
2. **RAM を揃える。** 同じ 8 GB か 16 GB を二枚にすれば、コンテナや仮想マシンにもっと余裕ができます。
3. **バックアップ。** 昨年の [Homelab レポート](/posts/sla_2025) で、ドライブは前触れなく壊れることを学びました。このマシンにもきちんとしたオフサイトバックアップが必要です。

## まとめ

約 1 万円で、この小さな NEC のマシンはカメラシステム、監視、ファイル共有、オフィススイート、テスト環境、列車ボードを同時に、しかも静かに動かしています。プロンプトが何と言おうと Raspberry Pi ではありませんし、だからこそより良い自宅サーバーだと思います。日本で自宅サーバーを始めたいなら、Pi を買う前に中古の業務用 PC の棚を覗いてみてください。
